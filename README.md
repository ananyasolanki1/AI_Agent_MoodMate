## Setup Instructions

1. **Create a `.env` file** in the root directory of the project.
2. **Add your Gemini API key** inside the file exactly like this:
   ```env
   GOOGLE_API_KEY=your_actual_api_key_here
   ```
3. **Install the required packages** via your terminal:
   ```bash
   pip install requests python-dotenv langchain langchain-google-genai
   ```
